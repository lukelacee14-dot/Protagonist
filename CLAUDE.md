This is the Protagonist app — a standalone mobile-first PWA version of the YourCharacter system from FocusFeed. All work goes in index.html only. Always push to origin main. This is a single branch project. Design system: background #0a0a0a, accent gold #c9a84c, fonts Fredoka One and DM Sans, pixel art RPG style. Mobile first — all layouts designed for 390px viewport width first.
This project is located in the Protagonist folder only. Never read, edit or push to any other project folder or repository. The only repository for this project is github.com/lukelacee14-dot/Protagonist. Never touch FocusFeed or any other project.
